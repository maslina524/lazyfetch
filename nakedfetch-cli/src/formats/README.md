# src/formats/

Here are the implementations of structures and functions for formatting values

Implementation in the files
- mod.rs - Common formatting implementations, mostly for strings
- display.rs - Wrapper structures that implement custom `Display` + `Debug`
- freq.rs - `Frequency` structure
- march.rs - `MicroArch` structure
- mem.rs - `MemorySize` structure
- percent.rs - `Percent` structure
- splitted.rs - `SplittedAnsiIter` structure
- temp.rs - `Temperature` structure
- time.rs - `Time` structure
